Tractor & JCB Fleet Khata Project
===================================

Structure:
- lib/main.dart: Complete app code with all 5 screens, contacts picker, SMS/WhatsApp triggers.
- pubspec.yaml: Project dependencies.
- android/: Android build configuration and permissions.
- .github/workflows/build.yml: GitHub Actions workflow to automatically build the APK online.

How to get your APK via GitHub:
1. Extract this zip file.
2. Create a new GitHub repository (can be Private or Public).
3. Upload all these files and folders to your repo (including the .github folder).
4. Go to the "Actions" tab in GitHub -> Run workflow (or it will run automatically on push).
5. In ~2-3 minutes, download your ready-to-install "Tractor-JCB-Khata-APK" from Artifacts!
